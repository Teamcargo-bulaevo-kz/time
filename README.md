# Аудит — проверка защищённости Android-телефона

Тренировочный сканер: собирает сведения о настройках безопасности и установленных приложениях,
подсвечивает риски (как у банковских троянов вроде RatHat) и сохраняет подробный отчёт в файл.
Ничего не меняет, интернет-разрешения у приложения нет.

**Скачать APK:** https://github.com/Teamcargo-bulaevo-kz/time/releases/download/latest/Audit.apk

## Что проверяется
- Версия Android и дата патча безопасности, признаки root, разблокированный загрузчик, SELinux.
- Блокировка экрана, шифрование, отладка по USB/Wi-Fi, Play Защита, прокси, частный DNS.
- Включённые спец. возможности, администраторы устройства, доступ к уведомлениям,
  СМС-приложение и клавиатура по умолчанию, пользовательские сертификаты, VPN.
- Каждое приложение: источник установки, скрытый значок, выданные разрешения,
  наложение поверх окон, право ставить APK, подпись, SHA-256 файла.

## Как пользоваться
1. Установите APK, откройте, нажмите «Сканировать».
2. «Отправить файл» — JSON-отчёт (лежит также в Загрузки/Audit) для подробного разбора.

Отчёт содержит список ваших приложений — отправляйте его только тому, кому доверяете.
